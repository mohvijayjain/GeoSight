================================================================================
IMAGE SPECIFICATIONS
================================================================================

Bands: 8 (in exact order)
  1. B2 (Blue) - 10m
  2. B3 (Green) - 10m
  3. B4 (Red) - 10m
  4. B8 (NIR) - 10m
  5. B11 (SWIR1) - Resampled to 10m
  6. B12 (SWIR2) - Resampled to 10m
  7. NDVI = (B8 - B4) / (B8 + B4)
  8. NDBI = (B11 - B8) / (B11 + B8)

Format: GeoTIFF (single file)
Data Type: Float32
Resolution: 10 meters per pixel
Source: COPERNICUS/S2_SR_HARMONIZED
Processing: Median composite, <10% cloud cover

================================================================================
API ENDPOINTS
================================================================================

GET /api/health
  - Check if backend is running

POST /api/fetch-image
  Body: {
    "bounds": {
      "minLon": 77.0,
      "minLat": 28.5,
      "maxLon": 77.3,
      "maxLat": 28.7
    },
    "cloudCover": 10
  }
  - Fetches Sentinel-2 image for specified area

GET /api/download/<filename>
  - Downloads the generated GeoTIFF file

================================================================================
TROUBLESHOOTING
================================================================================

Backend not starting:
  - Check port 5000 is available
  - Verify Earth Engine authentication
  - Run: python backend/app.py

Frontend not loading map:
  - Check Leaflet CSS is imported
  - Verify npm dependencies installed
  - Run: npm install in frontend directory

No images found:
  - Increase cloudCover parameter (try 20-30%)
  - Expand date range
  - Check coordinates are valid
